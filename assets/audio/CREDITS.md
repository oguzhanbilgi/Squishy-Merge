# assets/audio — placeholder sesler

Bu klasördeki tüm `.ogg` dosyaları **Kenney.nl** paketlerinden alınmış
**CC0 (Creative Commons Zero)** placeholder seslerdir. Ticari kullanımda
serbesttir, atıf zorunlu değildir.

Kaynak paketler:
- Impact Sounds — https://kenney.nl/assets/impact-sounds
- Interface Sounds — https://kenney.nl/assets/interface-sounds
- Digital Audio — https://kenney.nl/assets/digital-audio
- Music Jingles — https://kenney.nl/assets/music-jingles

| dosya | kaynak |
|---|---|
| `sfx_merge_pop.ogg` | Impact Sounds — `impactSoft_medium_000.ogg` |
| `sfx_danger.ogg` | Digital Audio — `lowDown.ogg` |
| `sfx_star_pat.ogg` | Interface Sounds — `pluck_001.ogg` |
| `sfx_chest_open.ogg` | Interface Sounds — `open_001.ogg` |
| `sfx_combo.ogg` | Digital Audio — `pepSound1.ogg` |
| `sfx_level_win.ogg` | Music Jingles — `jingles_PIZZI07.ogg` |
| `sfx_level_lose.ogg` | Music Jingles — `jingles_PIZZI16.ogg` |

## Değiştirirken
Dosya **isimlerini koru**. Kod bu isimlere `AudioManager.SFX_PATHS` üzerinden
bağlı; aynı isimle üzerine yazarsan kodda hiçbir değişiklik gerekmez.
