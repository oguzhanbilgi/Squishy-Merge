# Squishy Merge

Fizik tabanlı (Suika Game tarzı) squishy dumpling birleştirme mobil oyunu.
Godot 4.7 / GDScript. Android hedefli.

## Durum
Aktif geliştirme — bkz. `PROJECT_CONTEXT.md` (güncel durum) ve
`GAME_DESIGN.md` (oyun tasarımı spec'i).

## Geliştirme ortamı
- Godot 4.7.2 (stable)
- Android SDK + JDK (export için)

## Proje dosyaları
- `OWNER_WORKING_PROFILE.md` — genel AI işbirliği çalışma tarzı
- `PROJECT_CONTEXT.md` — bu projenin durumu, kapsamı, non-goals
- `GAME_DESIGN.md` — kilitli oyun tasarımı (tier'lar, level'lar, ödül sistemi)
- `CLAUDE.md` — Claude Code için repo talimatları
- `DEVLOG.md` — milestone bazlı kısa geliştirme kaydı
